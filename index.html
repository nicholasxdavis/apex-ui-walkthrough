Admin panel UI

Sign-in, Applications queue, Premier dealers CRM, Overview metrics

separate page template, section is main-admin-panel.liquid. you log in, then you get tabs for applications (pending / rejected / all, search, card expand, approve reject email delete), premier dealers (kpi strip, filters, sort, row expand), overview (four stat tiles, quick action links, recent activity table). theres also a link out to the public application page.

Application page UI

Numbered steps (contact, shop profile, location, experience), optional social block, consent, submit

main-application on the application page template. pricing tier strip up top (theme blocks), optional collapsed program copy, then the form in numbered fieldsets: your details, shop profile, address, experience and setup (radios + business type checkboxes + supplier field), optional social fields in a <details>, marketing checkbox + required terms, submit. success view replaces the form after send.
